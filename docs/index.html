Quick start

三步开始使用

  1. 准备运行环境使用 Java 21 启动 Leaves 1.21.10 或 1.21.11。
  2. 安装并生成配置把 JAR 放入 plugins/，启动一次服务器。
  3. 先演练离线扫描首次部署建议启用 dry-run，确认日志后再写回。
构建发布基线
mvn clean package

# 输出
target/LeavesAntiIllegal-3.0.0.jar
需要 1.21.11 兼容编译？ mvn -Pleaves-1.21.11 clean package
